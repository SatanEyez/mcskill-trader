# McSkill Trader — правила для агентов

1. **Сначала прочитай `MEMORY.md`** — это архив состояния проекта и правил передачи.
2. **Жёсткий порог контекста — 175 000 токенов.** При достижении 175k (и не позже 180k) немедленно останови работу, сделай компактизацию и передай всё следующему агенту по `MEMORY.md` (§0). Отдельной команды владельца ждать не нужно.
3. **Один API на PGlite.** Не запускай второй dev-стек; проверяй порты `4000`/`5173` и lock `server/data/pglite.lock`.
4. **Миграции:** применённые `001`–`005` не редактировать; новые изменения — только `006_*.sql`.
5. **Перед передачей:** один dev-стек, `npm run test:api` — 109/109 PASS, в `MEMORY.md` нет неопределённостей.
