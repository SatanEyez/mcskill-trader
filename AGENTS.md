# McSkill Trader — правила для агентов

1. **Сначала прочитай `MEMORY.md`**, если он есть локально — это архив состояния проекта и правил передачи. В репозиторий файл не входит (`.gitignore`), он живёт только на рабочей машине.
2. **Жёсткий порог контекста — 175 000 токенов.** При достижении 175k (и не позже 180k) немедленно останови работу, сделай компактизацию и передай всё следующему агенту по `MEMORY.md` (§0). Отдельной команды владельца ждать не нужно.
3. **База — MySQL** (не PostgreSQL). Подключение: `server/.env` → `MYSQL_HOST/PORT/USER/PASSWORD/DATABASE`. Схема — `server/migrations/*.sql` (диалект MySQL 8+). phpMyAdmin: http://127.0.0.1:8081. Один API на порту `4000`, Vite — `5173`; второй dev-стек не поднимать.
4. **Миграции:** применённые файлы не редактировать; новые изменения — только новым файлом `009_*.sql` (и далее по порядку).
5. **Перед передачей:** один dev-стек, `npm run test:api` — 109/109 PASS, в `MEMORY.md` нет неопределённостей.
